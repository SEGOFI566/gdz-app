# ГДЗ — готовые домашние задания

Мобильное приложение (Android/iOS) с десктопной версией для Windows.
Каталог: **класс → предмет → учебник → задание → решение**.

## Что уже есть

- Главный экран с выбором класса (5–11) и предметов.
- Список учебников по предмету и классу.
- Сетка заданий по номеру и подробный экран задания.
- Постраничный список заданий: 40 номеров на страницу с панелью страниц
  и диапазоном «1–40 из 535».
- Быстрый выбор страницы: нажми на диапазон в заголовке или на кнопку
  сетки в панели страниц — откроется список всех страниц с диапазонами
  заданий (например, «521–535»).
- Быстрый поиск внутри учебника: номер («527», «№ 527») или слово
  из условия; найденные задания подсвечиваются, Enter открывает решение.
- Пошаговое решение с ответом, скрытое по умолчанию.
- Поиск по номеру задания, условию, учебнику, автору и предмету;
  точные совпадения номера показываются первыми.
- Избранное с сохранением между запусками.
- Собственная база решений в `assets/data/catalog.json` — приложение
  работает офлайн, без сервера (11 предметов, 27 учебников, 2742 задания).
- Геометрия 7–9 классы (Атанасян, издание 2023–2026) — все 1431 задание:
  7 класс — № 1–461 (с. 8–120), 8 класс — № 462–929 (с. 123–228),
  9 класс — № 930–1431 (с. 229–364). Условия сверены с печатной книгой;
  разборы: gdz.ru (1115), reshak.ru (174), для 142 заданий, где подходящего
  разбора нет, показан подсказочный путь с указанием страницы — чужой текст
  из другого издания не подставляется.
- Русский язык 8 класс (Ладыженская/Баранов, 2026) — 150 упражнений
  с решениями и страницами.
- Русский язык 8 класс (Бархударов/Крючков/Максимов, 2026) — все 535
  упражнений (№ 1–535) с условиями, страницами 4–271 и решениями
  (в книге 271 страница, ISBN 978-5-09-127776-0).
- История (Мединский и др.): 8 класс — всеобщая история XVIII — начало XIX в.
  (136 заданий, с. 10–218); 9 класс — история России 1825–1914 (245 заданий,
  с. 6–375) и всеобщая история XIX — начало XX в. (211 заданий, с. 7–271).
  Условия, ответы и номера печатных страниц — из `budu5.com`.
- Остальные учебники: 169 заданий получили настоящие номера страниц из
  `budu5.com` (математика, алгебра, русский язык, история). 15 заданий по
  учебникам, которых там нет (физика, химия, английский, биология,
  информатика), взяты из `gdz.ru` и `reshak.ru` с реальными условиями и
  решениями; номер страницы неизвестен, поэтому плашка страницы скрыта —
  выдуманных номеров в каталоге нет.

## Источники данных

Учебники русского языка 8 класса:
- Т. А. Ладыженская, М. Т. Баранов, Л. А. Тростенцова и др. — 2026,
  издательство «Просвещение».
- С. Г. Бархударов, С. Е. Крючков, Л. Ю. Максимов и др. — 2026,
  издательство «Просвещение», 271 с., ISBN 978-5-09-127776-0.
  В УМК также входят рабочая тетрадь в двух частях, диагностические
  работы, аудиоприложение и методическое пособие.

Задания Бархударова сверены по изданию 2023–2026 (та же нумерация и те же
страницы, что в книге на 271 страницу):
- `budu5.com` — условия, номера страниц и ответы;
- `gdz-raketa.ru` — текстовые ответы для упражнений, где на budu5 ответ
  не опубликован (№ 22, 509, 513, 516, 520) и условие № 381.

Пересобрать задания Бархударова и проверить каталог:

```powershell
tool\rebuild.cmd
dart tool\validate_catalog.dart
```

## Структура

```
lib/
  main.dart                 — точка входа
  app_state.dart            — состояние: каталог, класс, избранное
  models.dart               — Subject, Textbook, TaskItem, Solution, Catalog
  theme.dart                — тема, цвета, склонения
  screens/
    root_shell.dart         — нижняя навигация + загрузка/ошибка
    home_screen.dart        — классы и предметы
    textbooks_screen.dart   — учебники предмета
    textbook_screen.dart    — задания учебника
    task_screen.dart        — условие и решение
    search_screen.dart      — поиск
    favorites_screen.dart   — избранное
  widgets/                  — карточки и переиспользуемые элементы
assets/data/catalog.json    — контент (предметы, учебники, задания, решения)
```

## Скачать для Android (APK)

На веб-версии под поиском есть баннер **«Скачать APK»**. В опубликованной
сборке он ведёт на APK из GitHub Releases (`v1.0.0`); локально можно указать
другой адрес через `--dart-define=APK_URL=...`.

Собрать APK:

```powershell
powershell -ExecutionPolicy Bypass -File tool\build_apk.ps1
```

Скрипт использует JDK 17 (`C:\dev\jdk17`) и Android SDK
(`C:\dev\android-sdk`), собирает release-APK и копирует его в
`build\download\gdz-app.apk`.

## Публичный доступ

Сайт: **https://SEGOFI566.github.io/gdz-app/**

Веб-версия публикуется в ветку `gh-pages`, GitHub Pages раздаёт её как
статику. APK лежит в GitHub Releases и скачивается кнопкой «Скачать APK».

Пересобрать и опубликовать только веб (APK не собирается и не загружается):

```powershell
tool\ui_publish.cmd
```

Скрипт проверяет каталог (`VALIDATION OK`), анализирует Dart-код, собирает
веб через кэшированный Flutter Tools snapshot (обходит зависание `flutter.bat`
на этой машине), пушит ветку `gh-pages` и коммитит исходники в `main`.
APK в релизе `v1.0.0` остаётся без изменений.

Временный адрес без GitHub — туннель Cloudflare (работает, пока запущены
сервер и туннель):

```powershell
# терминал 1 — сайт
dart tool\serve.dart build\web 8080

# терминал 2 — публичная ссылка
C:\dev\cloudflared.exe tunnel --url http://localhost:8080
```

Cloudflared выведет адрес вида `https://что-то.trycloudflare.com`.

## Как добавить решение

1. Открой `assets/data/catalog.json`.
2. Добавь учебник в `textbooks` (если его ещё нет).
3. Добавь задание в `tasks`:

```json
{
  "id": "math-5-99",
  "textbookId": "math-5",
  "number": "99",
  "page": 30,
  "condition": "Текст условия",
  "solutions": [
    {
      "id": "math-5-99-s1",
      "author": "Команда ГДЗ",
      "rating": 4.9,
      "steps": ["Шаг 1", "Шаг 2"],
      "answer": "Ответ"
    }
  ]
}
```

4. Перезапусти приложение (`r` в терминале Flutter).

## Следующие шаги

- **Сервер и общая база**: Supabase (Postgres + Auth + Storage) вместо
  локального JSON — чтобы обновлять контент без релиза приложения.
- **Админ-панель**: импорт заданий и решений из CSV/JSON, модерация.
- **Android/iOS**: установить Android Studio + JDK, собрать `flutter build apk`.
  Для iOS нужен Mac (ограничение Apple).
- **Монетизация**: реклама или подписка на расширенные разборы.
- **Права**: решения пишем сами; условия заданий и сканы учебников
  использовать без разрешения правообладателя нельзя.
